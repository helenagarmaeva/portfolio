# Solok Cosmetics: материалы для завершения

Страница подготовлена в отдельной ветке `feat/solok-case` и пока не опубликована
в основной версии портфолио. `solok.html` и `solok-en.html` используют общие
анимации появления, навигацию и эффект искажения кейса ДельтаБезопасности.
Текущая обложка взята из предоставленного `public/solok.png`.

На 17 октября 2026 года обе ссылки из задания недоступны из рабочей среды:
HTTPS-соединение завершается `Tunnel connection failed: 403 Forbidden`.
Повторная попытка с расширенным сетевым доступом дала тот же ответ.
Поэтому текст исследований и брендинга не скопирован, а фотографии и записи
работающего магазина не заменены вымышленными материалами.

Источники пользователя:

- https://solokcosmetics.ru/
- https://elenagarm.notion.site/Solok-Cosmetics-3aad48fbae2780e0a4d5d80d6ebca965?pvs=74

## Необходимые материалы

| Место на странице (`data-solok-slot`) | Материал |
| --- | --- |
| `main` | MP4 плавной прокрутки всей главной страницы магазина |
| `research-1`, `research-2` | Два изображения из раздела исследований старого портфолио |
| Раздел «Исследования» | Оригинальный текст из Notion |
| `scrub-builder` | MP4 взаимодействия с конструктором скрабов |
| `skin-quiz` | MP4 прохождения теста на тип кожи |
| `add-to-cart` | MP4 добавления товара в корзину |
| `product` | MP4 просмотра карточки товара |
| `mobile-home`, `mobile-catalog`, `mobile-product` | Скриншоты мобильной главной, каталога и карточки товара |
| `branding-1`, `branding-2` | Изображения из раздела брендинга старого портфолио; количество уточняется по материалам |
| Раздел «Брендинг» | Оригинальный текст из Notion |

Изображения и MP4 можно передать в `public/solok/`, тексты — отдельным документом
или сообщением. Имена файлов произвольные. Второй вариант — разрешить доступ
к двум исходным сайтам: тогда записи и скриншоты можно подготовить из браузера.
Размеры, подписи и число материалов брендинга нужно сверить с оригиналом.

## После получения материалов

1. Заменить отмеченные `data-solok-slot` блоки реальными материалами, вставить
   оригинальные тексты и обновить английский перевод.
2. Для видео использовать такую же структуру `data-animated-media`,
   `data-distort-frame`, `video[data-distort][data-distort-native-idle]` и невидимую
   `.video-toggle`, как в `delta.html`. У демонстраций обёртка
   `.case-screen-media`: на компьютере запуск при наведении, на телефоне —
   по нажатию. Главный ролик запускается автоматически в области видимости.
3. Подготовить H.264 MP4 с `faststart`, без аудио, и постеры из первых кадров.
   У главного видео предусмотрена рамка 16:10; исходные пропорции нужно сохранить.
   Исходники хранить вне `public/`, публиковать только используемые версии.
4. Удалить заметку черновика и стили `.solok-pending-*`, проверить сценарии
   воспроизведения, искажение, язык, мобильную версию и однократное появление.
5. Обновить описание кейсов в README, затем перенести завершённую ветку в `main`.
   Пока черновик остаётся в отдельной ветке, основное портфолио не меняется.
