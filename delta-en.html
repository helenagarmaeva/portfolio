Delta Security

Web / B2B / Dashboard

About the company

Delta Security is a B2B service for comprehensive due diligence and business risk monitoring.

The task

Simplify working with large amounts of data and help users find important information and assess risks faster.

My role

UX research, design system development, prototyping, and UI design.

UX research

I analyzed the interface, user journeys, and data structure to identify the main sources of information overload and friction when using the service.

Redesign

I restructured the information architecture of the profiles, grouped related data, and reduced visual noise. I added an AI-powered widget that analyzes company information and generates a concise summary with a risk assessment. As a result, key information became easier to find and compare.

Less visual noise

I removed excessive borders and secondary accents.

A new hierarchy

Key information has more space, and all data is organized into widgets.

Faster risk assessment

I added an overall risk score and a written summary.

Individual profile

Screens

Widgets can switch between different ways of displaying data depending on the user’s task. To view details and edit information, I designed a system of modal dialogs that preserves the context of the main profile.

Design system

I created a system of components and semantic color tokens for light and dark themes. Interactive elements include the key states: default, hover, pressed, and disabled. A neutral palette reduces visual noise, while status colors are reserved for meaningful highlights.

Result

The redesign brought fragmented data into a clear system and reduced visual noise while preserving access to detailed information.
