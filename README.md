# Портфолио Елены Гармаевой

Верстка по предоставленному макету: первый экран на всю высоту окна, блок из четырех кейсов и фиксированная кнопка RU. Фон ровный, `#000000`, без полосок и постоянного движения. WebGL-кисть оставляет затухающий след с переливающимися краями по принципу экранного рисования на Lusion. Текст и карточки остаются читаемыми поверх эффекта.

Наведение на CV, Telegram и LinkedIn показывает стрелку слева под углом 45° вверх вправо и прокручивает текст по вертикали. У почты анимируется подчеркивание. Карточки получают стрелку перед названием. Заголовки раскрываются по буквам с небольшим поворотом, абзацы — по строкам из-под маски. Обложки кейсов входят с противоположных сторон, подписи появляются волной, а описания коротко перебирают символы, как на Lusion. При повторном входе в экран анимации воспроизводятся снова; при изменении ширины абзацы заново разбиваются на строки. Кнопка «КЕЙСЫ» останавливает прокрутку точно у начала секции, без остатка первого экрана. Lenis добавляет инерцию колесу мыши; сенсорная прокрутка и режим уменьшенной анимации остаются нативными.

## Запуск

Node.js 22.12+ и npm; в облачной среде проверен Node.js 24.

```bash
npm ci
npm run dev -- --port 5173 --strictPort
```

## Сборка и проверки

```bash
npm run build
npm test
```

Браузерные проверки используют системный `/usr/bin/chromium`, если он доступен. Можно указать другой путь через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Если системного браузера нет, установите браузер Playwright командой `npx playwright install chromium`.

```bash
npm run preview -- --port 4173 --strictPort
TEST_BASE_URL=http://127.0.0.1:4173 npm test
```

Проверяются: высота первого экрана, размер/цвет курсора, фиксированная RU, стрелки и наведение, клавиатура, переход к кейсам, появление букв/строк/карточек, целостность текста после изменения ширины окна, точный переход к началу кейсов, ровный черный фон, реальное рисование и затухание WebGL-следа, мобильная версия, режим уменьшенной анимации и отсутствие WebGL.

## Эффект и доступность

`src/cursor-paint.js` содержит независимую WebGL 2 реализацию экранной кисти: направленная инерция, перенос и сглаживание поля движения, шумовое искривление и две маски затухания. Ширина кисти зависит от движения мыши, цвет кромки — от направления. Разрешение поля составляет четверть разрешения экрана; постоянный цвет фона не искажается и не анимируется. Ресурсы пересоздаются при изменении окна; расчет останавливается в скрытой вкладке и после затухания следа. На сенсорных экранах нет искусственного курсора и след не мешает прокрутке. `prefers-reduced-motion` отключает движение и появление элементов; при отсутствии WebGL остается ровный черный фон.

Референс — https://lusion.co/ . При обновлении эффекта были изучены доступная реализация экранной кисти и ее параметры: радиус до `max(40, ширина / 20)`, диапазон движения 100 px, инерция 0.8, затухание направления 0.975, маски 0.95/0.8, хроматическая фаза 40 и сдвиг каналов 0/1/2. Эффект реализован самостоятельно для ровного черного фона портфолио; исходная 3D-сцена Lusion не копируется. Покадровое совпадение двух сайтов не заявляется, поскольку фон и содержимое различаются.
