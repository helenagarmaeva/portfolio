# Портфолио Елены Гармаевой

Верстка по предоставленному макету: первый экран на всю высоту окна, блок из четырех кейсов и фиксированная кнопка ENG. Фон ровный, `#040404`, без верхнего градиента, полосок и постоянного движения. Описание о дизайнере — два абзаца с интервалом, 18 px, выровненные по ширине блока контактов. Названия проектов — 20 px, подзаголовки — 18 px на всех экранах. Фавикон — крупный круглый кадр оригинальной фотографии. SVG содержит саму фотографию, чтобы браузер мог отобразить её в иконке без внешних загрузок; исходный портрет не изменён. Кнопка «Кейсы» опущена ближе к нижнему краю первого экрана. WebGL-кисть оставляет затухающий след с переливающимися краями по принципу экранного рисования на Lusion. Текст и карточки остаются читаемыми поверх эффекта. На фотографии это же поле движения смещает пиксели изображения и добавляет лёгкую цветную кромку; после затухания исходное изображение восстанавливается.

Наведение на CV, Telegram и LinkedIn показывает стрелку слева под углом 45° вверх вправо и прокручивает текст по вертикали. У почты анимируется подчеркивание. Карточки получают стрелку перед названием. Заголовки раскрываются по буквам с небольшим поворотом, абзацы — по строкам из-под маски. Обложки кейсов входят с противоположных сторон, подписи появляются волной, а описания коротко перебирают символы, как на Lusion. При каждом повторном входе в область появления анимации воспроизводятся снова: выход за границу наблюдателя сразу сбрасывает карточку и подписи; при изменении ширины абзацы заново разбиваются на строки. Кнопка «КЕЙСЫ» останавливает прокрутку точно у начала секции, без остатка первого экрана. Lenis добавляет инерцию колесу мыши; сенсорная прокрутка и режим уменьшенной анимации остаются нативными.

Контактные кнопки и почта имеют размер шрифта 20 px на всех экранах. На сенсорных устройствах подчёркивание почты толщиной 0,5 px, диагональные стрелки контактов и стрелки названий проектов видны постоянно; для стрелок зарезервировано место в строках. На компьютере курсор — прозрачный круг 20 × 20 px с обводкой 1 px цвета `#e7e7e7`. На мобильных экранах работают те же появления букв и строк, включая повторный запуск при скролле и пересчёт строк после изменения ширины.

## Запуск

Node.js 22.12+ и npm; в облачной среде проверен Node.js 24.

```bash
npm ci
npm run dev -- --port 5173 --strictPort
```

## Сборка и проверки

```bash
npm run build
npm test
```

Браузерные проверки используют системный `/usr/bin/chromium`, если он доступен. Можно указать другой путь через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Если системного браузера нет, установите браузер Playwright командой `npx playwright install chromium`.

```bash
npm run preview -- --port 4173 --strictPort
TEST_BASE_URL=http://127.0.0.1:4173 npm test
```

Проверяются: высота первого экрана, размер/цвет курсора, фиксированная ENG, стрелки и наведение, клавиатура, переход к кейсам, появление букв/строк/карточек, целостность текста после изменения ширины окна, точный переход к началу кейсов, три повторных входа в кейсы, ровный черный фон, искажение/восстановление пикселей фото, синхронизация фото с прокруткой и восстановление после потери WebGL-контекста, реальное рисование и затухание WebGL-следа, мобильная версия, режим уменьшенной анимации и отсутствие WebGL.

## Эффект и доступность

`src/cursor-paint.js` содержит независимую WebGL 2 реализацию экранной кисти: направленная инерция, перенос и сглаживание поля движения, шумовое искривление и две маски затухания. Ширина кисти зависит от движения мыши, цвет кромки — от направления. Для деликатного эффекта на чёрном фоне `TRAIL_VISIBILITY = .12` ограничивает яркость кромки, а `REFRACTION_STRENGTH = .35` смягчает искажение фотографии (сдвиг до 4,9 CSS px). Яркость самой фотографии сохраняется. Разрешение поля составляет четверть разрешения экрана; постоянный цвет фона не искажается и не анимируется. Расчёт возобновляется при прокрутке, чтобы фиксированный canvas точно следовал положению фото и его появлению. После потери/восстановления контекста текстура пересоздаётся, а на время восстановления виден HTML-оригинал. Ресурсы пересоздаются при изменении окна; расчет останавливается в скрытой вкладке и после затухания следа. На сенсорных экранах нет искусственного курсора и след не мешает прокрутке. `prefers-reduced-motion` отключает движение и появление элементов; при отсутствии WebGL остается ровный черный фон.

Референс — https://lusion.co/ . При обновлении эффекта были изучены доступная реализация экранной кисти и ее параметры: радиус до `max(40, ширина / 20)`, диапазон движения 100 px, инерция 0.8, затухание направления 0.975, маски 0.95/0.8, хроматическая фаза 40 и сдвиг каналов 0/1/2. Эффект реализован самостоятельно для ровного черного фона портфолио; исходная 3D-сцена Lusion не копируется. Покадровое совпадение двух сайтов не заявляется, поскольку фон и содержимое различаются.
