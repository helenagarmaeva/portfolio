# Портфолио Елены Гармаевой

Верстка по предоставленному макету: первый экран на всю высоту окна, блок из четырех кейсов и фиксированная кнопка RU. Общий WebGL-фон рисует затухающий фиолетовый след мыши и преломляет полоски с помощью поля скорости жидкости. Текст и карточки остаются читаемыми поверх фона.

Наведение на CV, Telegram и LinkedIn показывает стрелку слева и прокручивает текст по вертикали. У почты анимируется подчеркивание. Карточки получают стрелку перед названием. Секции плавно появляются при прокрутке. Lenis добавляет инерцию колесу мыши; сенсорная прокрутка и режим уменьшенной анимации остаются нативными.

## Запуск

Node.js 22.12+ и npm; в облачной среде проверен Node.js 24.

```bash
npm ci
npm run dev -- --port 5173 --strictPort
```

## Сборка и проверки

```bash
npm run build
npm test
```

Браузерные проверки используют системный `/usr/bin/chromium`, если он доступен. Можно указать другой путь через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Если системного браузера нет, установите браузер Playwright командой `npx playwright install chromium`.

```bash
npm run preview -- --port 4173 --strictPort
TEST_BASE_URL=http://127.0.0.1:4173 npm test
```

Проверяются: высота первого экрана, размер/цвет курсора, фиксированная RU, стрелки и наведение, клавиатура, переход к кейсам, появление карточек, реальное изменение пикселей WebGL при движении мыши, мобильная версия, режим уменьшенной анимации и отсутствие WebGL.

## Подключение материалов

Все материалы задаются в `src/content.js`: `portrait`, ссылки `contacts`, названия/описания/обложки/ссылки `projects`. Локальные изображения положите в `public/` и укажите относительный путь, например `./portrait.jpg`. Пустые ссылки оставляют анимированные кнопки без перехода, как согласовано. Почта уже открывает `mailto:helenagarm@gmail.com`.

Оригинальный файл портрета не был предоставлен; пока используется круг с инициалами. Обложки и названия кейсов — плейсхолдеры из макета. RU пока обозначает язык страницы; английская версия не добавлялась.

## Эффект и доступность

`src/fluid.js` содержит независимую WebGL 2 симуляцию: адвекция, вихри, дивергенция, давление и проекция скорости. Фон искажается полем скорости и градиентом следа. Разрешение полей и количество инъекций ограничены, ресурсы пересоздаются при изменении окна, расчет останавливается в скрытой вкладке. На сенсорных экранах нет искусственного курсора и след не мешает прокрутке. `prefers-reduced-motion` отключает движение и появление элементов; при отсутствии WebGL используется статический фон.

Референс — https://lusion.co/ . Доступ к этому сайту из среды был ограничен, поэтому покадровое сравнение с оригиналом пока не выполнено. Эффект реализован самостоятельно по описанию пользователя.
